# Sprint execution template

Tạo file `Pxx-Sxx-<slug>.md` khi sprint bắt đầu, không tạo trước hàng chục file rỗng.

```md
# Pxx-Sxx — Tên sprint

Status: Not started | In progress | Blocked | Done

## Mục tiêu và dependency

...

## Task checklist

- [ ] Pxx-Sxx-DB01 ...
- [ ] Pxx-Sxx-BE01 ...
- [ ] Pxx-Sxx-FE01 ...
- [ ] Pxx-Sxx-API01 ...
- [ ] Pxx-Sxx-XL01 ...
- [ ] Pxx-Sxx-QA01 ...
- [ ] Pxx-Sxx-DOC01 ...

## API/data/state contract

...

## Acceptance criteria / DoD

...

## Verification evidence

| Command/scenario | Result | Date/notes |
| ---------------- | ------ | ---------- |

## Risks, decisions, known issues

...

## Demo script

...
```

Quy tắc: checkbox chỉ tick khi có bằng chứng; lỗi môi trường ghi Blocked/Not verified, không đổi thành Done.
